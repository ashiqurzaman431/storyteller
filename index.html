How this works

Scenes live on a free canvas — drag any card wherever you want, or use the arrange icon in the sidebar to lay everything out.

Branch Scene Sets

Select a scene, open the Scene panel, and click Fork branch. The new set gets an id like BSS.05A. Forking from inside a branch creates nested sub-branches automatically.

Connect lines

Press connect in the mode bar, then click two scenes in order. Any scene can connect to any other.

Storylines

Press storyline, click scenes in reading order, then confirm in the Scene panel. That path renders bold across the canvas.

Saving

Everything autosaves. Use the export/import arrows in the sidebar for JSON backups.
